Class SettingsXmlWriter

Namespace
MCM.Abstractions.Xml
Assembly
MCMv5.dll

Writes current values back into the file a <Settings> block was declared in, as Value attributes on the property elements. Only those attributes change: the file is edited as text, not re-serialized, so comments, quotes, attribute layout, line endings, encoding and byte order mark stay as they are.

SetValues(string, string, IEnumerable<KeyValuePair<string, string>>)

Sets the Value attribute of every listed property of the block in the file. Values are the text a Default attribute takes; a dropdown takes the option index. Ids without a matching property element are ignored. Returns false when the block is not in the file. The file is written in place, so links a mod manager deployed stay intact, and only when a value changed.
