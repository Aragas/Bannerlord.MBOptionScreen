Class ExternalGlobalSettings

Namespace
MCM.Abstractions.Base.Global
Assembly
MCMv5.dll

Global settings declared in XML (SettingsXmlModel) instead of code. MCM creates them for every <Settings> block found in the SubModule.xml of a loaded module, so a mod gets a settings page without referencing MCM. The declaring file is also the store: saving writes the current values back into it as Value attributes (SaveToFile()), where the mod reads them.
