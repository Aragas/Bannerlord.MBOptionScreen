Settings declared in XML instead of code. The block can be the root of its own file or a child of <Module> in a mod's SubModule.xml, where MCM discovers it without the mod referencing MCM. The file is also the store: every property carries its Default, and the current value is written back as a Value attribute by MCM or by the mod itself (see SettingsXmlWriter).

<Settings>
  <Group Name="{=id}General">
    <Bool Id="Enabled" DisplayName="{=id}Enabled" HintText="{=id}..." Default="true" RequireRestart="false" />
  </Group>
  <Preset Id="off" DisplayName="Off"><Property Id="Enabled" Value="false" /></Preset>
</Settings>

Properties placed directly under <Settings> go to the default (Misc) group. In a SubModule.xml, Id defaults to the module id and DisplayName to the module name.
